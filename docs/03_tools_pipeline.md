# Инструменты и пайплайн (v2)

Обозначения: ✅ проверено в работе у меня в контейнере · 🔑 заработает, если дать ключ · 👤 делаете вы у себя · ⛔ недоступно отсюда · 💤 знаю, но не нужно.

## Пайплайн серии

```
1. Сценарий            я → docs/, scenes/epXX.json (реплики, планы, эмоции)
2. Черновая озвучка    я → engine/voice.py → audio/epXX/*.wav            ✅
3. Аниматик            я → engine/cutout.py на болванках → проверяем тайминг ✅
4. Картинки            вы → Gemini / Flow (Nano Banana Pro) → incoming/    👤
5. Вырезка             я → engine/cut.py, engine/jaw.py → assets/          ✅
6. Чистовая озвучка    вы голосом / Gemini TTS → заменить файлы в audio/   👤 🔑
7. Сборка и рендер     я → engine/cutout.py → out/epXX.mp4                 ✅
8. Публикация          вы
```

Главное удобство: сцена пишется репликами. Длительность плана, субтитры и движение челюсти движок берёт из аудиофайла. Заменили черновой голос на чистовой — всё подстроилось само.

## Что есть в репозитории

| Файл | Что делает |
|---|---|
| `engine/cutout.py` | Рендер сцены: слои-фотографии, герои из деталей, 12 поз в секунду, дрожание вырезок, бумажная кромка и тень, смена эмоций, камера (наезд, удар, тряска), экран ноутбука с печатающимся текстом, плашки, субтитры, зерно, сведение и выравнивание громкости |
| `engine/voice.py` | Черновая озвучка всех реплик сцены: три русских голоса, темп, высота, «робот» для Клавы |
| `engine/cut.py` | Вырезка фона нейросетью или по цвету; разрезает лист с деталями на отдельные файлы |
| `engine/jaw.py` | Отрезает челюсть у головы для «говорения» |
| `engine/make_placeholders.py` | Болванки героев и фонов для аниматика |
| `scenes/ep01_pilot.json` | Пилот целиком, 60 секунд, 17 планов |
| `.claude/skills/montage-episode/` | Наш собственный скилл: как собирать серию. Подхватывается в следующих сессиях |

| Плагин **voice-of-customer** | можно поставить | Достаёт дословные жалобы людей с Reddit и Hacker News. Для нас — источник шуток: реальные формулировки боли вайбкодеров |
| Плагин **Manifold** | можно поставить | Бесплатные данные по Instagram и TikTok, разбор вирусных роликов |

| Вручную | 👤 | Telegram-каналы мемов про вайбкодинг, тег «вайбкодинг» на Pikabu, r/vibecoding |

### Сценарий

### Картинки
| Инструмент | Статус | Заметка |
|---|---|---|
| **Nano Banana Pro** в Gemini / Flow | 👤 | Основной путь, входит в подписку. На тарифе Pro — около 1 000 кредитов Flow в месяц (цифры у сторонних обзоров расходятся — сверьте в своём аккаунте) |
| Gemini API | 🔑 | Сервер Google отсюда доступен. С ключом из AI Studio я смогу генерировать сам, но это **отдельные деньги**, не подписка: около $0,13 за картинку Pro, $0,03 за младшую модель; бесплатного уровня для картинок нет |
| Плагин **image-generation** | можно поставить | Гайд по промтам для Gemini Image |
| Unsplash (подключён) | ⛔ пока | Настоящие фото хрущёвок и вещей. Не пускает: **не подтверждена почта** в аккаунте Unsplash |

### Вырезка
| Инструмент | Статус | Заметка |
|---|---|---|
| rembg: ISNet, BiRefNet | ✅ | Убирает фон. Проверено на листе с деталями |
| Ключ по цвету | ✅ | Для ровного серого фона — быстрее и чище нейросети |
| SAM 3 (Meta) | не пробовал | Выделяет по слову: «голова», «рука». Открытая модель; пригодится, если придётся резать готовое фото на части. На процессоре будет медленно |
| Qwen-Image-Layered | не пробовал | Раскладывает одну картинку на слои с прозрачностью и дорисовывает то, что было закрыто. Идея: разложить фото комнаты на передний, средний и задний план, чтобы камера двигалась с параллаксом. Есть на Hugging Face |
| DepthFlow, parallax-maker | не пробовал | То же через карту глубины: «объёмное» движение по плоскому фото |

### Голоса
| Инструмент | Статус | Заметка |
|---|---|---|
| **Piper** (локально) | ✅ | Русские голоса, работает без ключей и интернета. Качество черновое: для аниматика, не для публикации. Перед публикацией проверить лицензию голоса |
| **Свой голос** | 👤 | Лучший вариант для Гоши и Лёвы: запись на телефон, файл кладётся вместо чернового |
| **Gemini TTS** | 🔑 | Несколько голосов в одном диалоге, интонация задаётся словами. В API есть бесплатный уровень. Поддержку русского у текущей версии поиск не подтвердил — проверю, когда будет ключ |
| ElevenLabs | 💤 | Сильнее всех по эмоциям, платно. Коннектор в каталоге — про голосовых агентов, не про озвучку |
| Silero | не пробовал | Хороший русский локально; бесплатные модели — без коммерческого использования |
| Online-голоса Edge | ⛔ | Не пускает наш прокси |

## Что от вас нужно, чтобы разблокировать

1. **Сгенерировать 11 картинок** для пилота — список в `04_pilot_script.md`.
2. **Установить плагины** из карточки: image-generation, Remotion, voice-of-customer. Прошлая карточка пока не сработала — в аккаунте плагинов не вижу.
3. **По желанию:** кредиты vidIQ (статистика ниши), подтвердить почту в Unsplash (настоящие фото), ключ Gemini API из AI Studio (я сам озвучиваю и генерирую; ключ вводится в защищённую форму, не в чат).
