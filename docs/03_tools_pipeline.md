# Инструменты, скиллы и пайплайн

## Пайплайн одной серии

```
 Идея / сценарий (я + вы)          docs/01_show_bible.md → scripts/epXX.md
        │
 Генерация (вы, Google)            Nano Banana Pro: персонажи, эмоции, развёртки, фоны
        │  → incoming/ или Google Drive
 Вырезка (я)                       engine/cut.py  (rembg/BiRefNet или ключ по цвету)
        │                          engine/jaw.py  (челюсть для речи)
 Озвучка (вы или я)                Gemini TTS (мультиспикер) / свои голоса → audio/
        │                          + Rhubarb Lip Sync → тайминг рта (опционально)
 Сборка сцены (я)                  scenes/epXX.json — планы, ракурсы, эмоции, субтитры
        │
 Рендер (я)                        engine/cutout.py → out/epXX.mp4 (1080×1920, 24 fps)
        │
 Финиш                             громкость, обложка, публикация (vidIQ / вручную)
```

## Что уже работает в репозитории

| Файл | Что делает |
|---|---|
| `engine/cutout.py` | Движок перекладки: фото-слои, риги персонажей (тело → голова → челюсть, руки), ступенчатая анимация 12 поз/с, «бойл» (микросдвиги вырезок), белая бумажная кромка и тень, смена эмоций, челюсть-хлопушка, камера (наезды, снап-зум, тряска), плашки, субтитры ситкома, зерно/виньетка/мерцание, микс аудиодорожек |
| `engine/cut.py` | Вырезает фон нейросетью (rembg: BiRefNet / ISNet) или ключом по цвету; `--split` режет лист-развёртку на отдельные PNG-детали |
| `engine/jaw.py` | Режет голову по линии рта на «верх» и «челюсть» с тёмной «пастью» |
| `engine/make_placeholders.py` | Болванки персонажей/фона для тестов, пока нет генераций |
| `scenes/demo.json` | Демо-сцена на 14 сек: 5 планов, все приёмы движка |

Рендер: `python3 engine/cutout.py scenes/demo.json -o out/demo.mp4` (≈5 сек рендера на 1 сек видео).
Один кадр для проверки: `--still 7.5 -o out/frame.png`.

## Найденные скиллы и плагины Claude

| Что | Статус | Чем полезно нам |
|---|---|---|
| **vizavi-motion** | ✅ уже включён | Кинетическая типографика, заставки, motion-плашки («ПЯТНИЦА. 23:58», интро шоу) |
| **image-generation** (плагин) | можно поставить | Гайд по промтингу Gemini Image / Imagen — для доводки промтов персонажей |
| **IT Reelsmaker** (плагин) | можно поставить | Пословные субтитры, мастеринг громкости, рендер 1080×1920 — для финиша (заточен под говорящую голову, но эти части применимы) |
| **animation-studio** (плагин) | можно поставить | Мультики, нарисованные кодом, + синтез саундтрека в код, вертикаль 9:16. Не фото-коллаж, но полезен подход «одна партитура для картинки и звука» — можно подсмотреть для джингла |
| BlitzReels, ManyMotions Comedy Skit, Abracadabrax | платные внешние сервисы | Генерят готовые ИИ-ролики — не наш стиль, пропускаем |

## Подключённые коннекторы, которые пригодятся

- **Google Drive** — обмен: вы складываете генерации в папку, я забираю и режу.
- **Hugging Face** — облачные модели вырезки (BiRefNet, SAM2) и, при желании, TTS.
- **vidIQ** — анализ трендов Reels/TikTok по нише, подбор заголовков, публикация рилса в Instagram.
- **Unsplash** — стоковые фото для фонов/реквизита (нужно подтвердить почту в аккаунте Unsplash — сейчас не пускает).

## Внешние инструменты

**Генерация (ваша подписка Google AI):**
- **Nano Banana Pro (Gemini 3 Pro Image)** — персонажи, эмоции, развёртки, фоны. Держит лицо между генерациями по референсу (до ~14 референс-картинок, первые 6 — с высокой точностью).
- **Flow / Whisk** — удобная доска для серий генераций с референсами.
- **Veo 3.1** — не основной инструмент (наш стиль — статика), но годится для редких «живых» вставок-контрастов: например, «реальный» кадр солнца в серии «Лимиты».
- **Gemini TTS (AI Studio)** — озвучка с несколькими голосами в одном диалоге, умеет русский, управляется текстом («скажи устало», «шёпотом»).

**Вырезка:** rembg + BiRefNet (стоит, проверено), SAM2 — для сложных краёв (волосы, кудри Лёвы).

**Липсинк:** [Rhubarb Lip Sync](https://github.com/DanielSWolf/rhubarb-lip-sync) — по аудио выдаёт тайминг фонем; для челюсти-хлопушки хватает моментов «говорит/молчит», которые можно взять и из тишины в аудио.

**Субтитры по аудио:** Whisper — пословные тайминги, чтобы субтитры точно попадали в реплики.

**Если захочется руками:** OpenToonz (бесплатно), Moho, Cartoon Animator — классические перекладочные программы с костями; CapCut — быстрая финальная доводка.
