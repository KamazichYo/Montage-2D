# Правила промтов для Nano Banana Pro

Сохранено, чтобы не терялось между сессиями. Источник — роль «Lead Prompt Architect», которую задал пользователь, плюс наши правила для деталей персонажа.

## Структура промта

Английский, плотное режиссёрское описание, 80–160 слов, без заголовков внутри. Цепочка:

1. **Anchor & Medium** — формат, стиль, общий план («A raw studio photograph…»).
2. **Subject & Micro-details** — герой, поза, анатомия, материалы, контакт с окружением.
3. **Spatial layout** — передний / средний / задний план, что что перекрывает. Использовать пространственные привязки: *in the immediate foreground, left third, upper-right quadrant*.
4. **Typography** — если есть текст: точная строка в двойных кавычках `"ТЕКСТ"`, шрифт, способ нанесения.
5. **Lighting & colour** — схема света, температура в Кельвинах, поведение теней.
6. **Optics / execution** — объектив и диафрагма, в конце соотношение сторон.

## Запреты и усилители

- Никаких `masterpiece, best quality, 8k, uhd, trending on artstation, award-winning, hyperrealistic`. Вместо них — оптика, свет, материалы.
- Против «ИИ-пластика»: поры кожи без ретуши, пух на коже, ткань с ворсом и катышками, лёгкое плёночное зерно, пылинки, микроцарапины.
- Физика: как свет ложится на ткань, как тяжёлое тянет вниз, как цветной свет даёт рефлекс.

## Формат ответа пользователю

1. Разбор концепта (1–2 предложения).
2. Три варианта: **Core Vision** (точный) / **Mood & Drama** (кинематографичный) / **Artistic / Tactile** (стилизованный) — каждый в своём блоке `text`.
3. Одна короткая команда для доработки в том же чате.

Для деталей персонажа три варианта не нужны — там нужен один точный и одинаковый по свету: даю один промт на деталь + команды правки.

## Правила для частей персонажа

- К **каждой** генерации прикладываем оба эталонных листа (спереди, сзади). Первая строка: *Using the attached reference sheets as the exact reference for face, hair, clothing and proportions…*
- Эталон — это уже картинка, а не мои первые описания. Если на картинке вышло иначе, чем в тексте, истиной считается картинка.
- Один блок света и фона во всех промтах (серый #8C8C8C, фронтальный софтбокс 5200K, без теней на фоне).
- Просим «в кадре только рука», а не «отрезанная рука»: так модель не рисует анатомические странности. Лишнее по краю кадра обрезаю я.
- Крупные части — по одной на картинку; головы и кисти — листами.
- Руки и ноги — только левые, правые отражаю.
- До 14 картинок-референсов, при этом по отзывам практиков первые 6 учитываются точнее — главные референсы кладём первыми.

## Имена файлов

`<герой>__<шаг>__<что>.png`, например `gosha__03__heads_front.png`. Эталоны лежат в `assets/chars/<герой>/ref/`.
