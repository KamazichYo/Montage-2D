# Сборка серии «Навайбкодили»

Сначала прочитай `docs/01_show_bible.md` (герои, структура, правила шуток). Инструменты и их статус — `docs/03_tools_pipeline.md`.

## Порядок

1. **Сценарий.** Одна «странная вещь», три ступени усиления, панч, конфессионал, добивка. 110–140 слов на 60 с, реплика до 8 слов, крючок в первой фразе. Таблицей в `docs/` — как `docs/04_pilot_script.md`.
2. **Сцена.** `scenes/epXX_name.json` — скопируй структуру `scenes/ep01_pilot.json` (cast, assets, rigs, sets, cams переиспользуются).
3. **Черновая озвучка:** `python3 engine/voice.py scenes/epXX.json` (`--force` — переозвучить всё).
4. **Проверка кадров:** `python3 engine/cutout.py scenes/epXX.json --still 12.5 -o out/f.png` — посмотри несколько стоп-кадров глазами до полного рендера.
5. **Рендер:** `python3 engine/cutout.py scenes/epXX.json -o out/epXX.mp4` (≈5 с на секунду видео — запускай в фоне).
6. **Превью для показа:** `ffmpeg -i out/epXX.mp4 -c:v libx264 -crf 28 -c:a aac out/epXX_preview.mp4`.

Зависимости: `pip install pillow numpy scipy rembg onnxruntime piper-tts`, системный `ffmpeg`.

## Формат сцены

```jsonc
{
  "cast":  { "g": { "name": "ГОША", "color": [255,160,60],
                    "voice": { "piper": "dmitri", "speed": 1.15, "pitch": 1.08 } } },
  "assets": { "bg_living": { "file": "bg_living.png", "bg": true }, "gosha_body": "gosha_body.png" },
  "rigs":  { "gosha": { "talk": { "dy": 22 }, "parts": [ /* body(root), head, jaw, arm, arm_back */ ] } },
  "sets":  { "living": [ { "id": "bg", "asset": "bg_living", ... }, { "id": "g", "rig": "gosha", "pos": [320,1600], "scale": 0.72 } ] },
  "cams":  { "wide": { "zoom": 1.0, "center": [540,1000], "push": 0.06 }, "cu_g": { "zoom": 1.9, "center": [320,1060] } },
  "shots": [
    { "set": "living", "cam": "cu_g",                 // декорация + именованная камера
      "lead": 0.9, "tail": 0.9,                       // паузы до первой и после последней реплики
      "with": { "g": { "face": [ { "t": 0, "asset": "gosha_head_smug" } ] } },   // правки слоёв по id
      "hide": ["laptop"],
      "dialogue": [
        { "who": "g", "text": "…Какие тесты?", "say": "Какие тесты?",   // say — как произнести
          "face": "gosha_head_shock",                 // сменить лицо говорящего на этой реплике
          "react": { "l": "lyova_head_smug" },        // лица слушающих
          "punch": 1.3, "gap": 0.4 }                  // удар камеры; пауза перед репликой
      ] },
    { "fill": [18,22,28],                             // экран ноутбука
      "card": { "text": "> напиши тесты", "mono": true, "align": "left", "size": 64,
                "bg": [18,22,28], "color": [120,255,140], "type": 22 },          // type — символов в секунду
      "dialogue": [ { "who": "k", "text": "Готово!" } ] }
  ]
}
```

- `dur` плана считается сам по аудио; задай числом только для планов без реплик.
- Аудио реплики: `audio/<имя сцены>/sNN_MM_<кто>.wav`. Чистовой дубль кладётся под тем же именем — тайминг, субтитры и челюсть перестроятся.
- Говорящий без рига (Клава) — только голос и субтитры.
- Координаты — в пикселях кадра 1080×1920; `pos` рига — точка под ногами (`anchor` тела `[0.5, 1.0]`).
- Слои без диалога по-прежнему можно анимировать вручную: `keys` (pos/rot/scale с `ease`), `swap`, `pop`, `show`, `say`.

## Новые картинки

- Промты для Nano Banana Pro пишем по правилам из `docs/08_nbp_prompt_rules.md`; чек-лист героя — `docs/07_character_checklist.md`.
- Старые промты — `docs/02_prompts.md`. Генерирует пользователь (Gemini / Flow), кладёт в `incoming/`.
- Вырезка: `python3 engine/cut.py incoming/x.png -o assets/chars/gosha [--split] [--key]`.
- Челюсть: `python3 engine/jaw.py assets/chars/gosha/gosha_head_neutral.png --mouth 0.74` → `_top.png` и `_jaw.png`.
- Все головы одного героя приводи к одному размеру и одной линии рта — иначе при смене эмоции голова «прыгает» не по-смешному.

## Правила вкуса

- Поза вместо движения; реплика = склейка; панч = удар камеры + смена головы в один кадр.
- Один стилевой трюк на серию (шесть пальцев при галлюцинации, мутные герои при сжатии контекста и т. п. — таблица в библии).
- Субтитры всегда. Крючок до любой заставки. Конец рифмуется с началом.
- Никаких реальных лиц без согласия, логотипов и чужой музыки.
